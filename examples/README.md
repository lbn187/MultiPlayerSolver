# Examples

- `kuhn3_gate.py` resolves every public subgame of three-player Kuhn poker
  and applies the gate at tolerance 0.02 (about twenty seconds).
- `nplayer_and_leduc.py` prints the tree sizes of the games, resolves one
  subgame of three- and four-player Kuhn, and resolves one second-round
  subgame of three-player Leduc (about a minute).
